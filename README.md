# BNW — Уличный бой

Оригинальная 2D-игра в жанре street beat 'em up, созданная на чистых HTML/CSS/JavaScript без библиотек.

## Уже работает
- персонаж и уличная локация;
- несколько противников;
- обычный удар 👊 и сильный удар 🦵;
- блок 🛡;
- здоровье и очки;
- волны врагов и уровни;
- управление мышью, клавиатурой и сенсорными кнопками;
- пауза и экран победы/поражения.

## Управление
**Телефон:** левый стик — движение, кнопки справа — атака и блок.

**ПК:** A/D или стрелки — движение, Space/J — удар, K — сильный удар, Shift — блок.

Игра запускается из `index.html`.
